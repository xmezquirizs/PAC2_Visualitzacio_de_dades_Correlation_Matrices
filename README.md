# PAC2_Visualitzacio_de_dades_Correlation_Matrices

# Anàlisi de Correlació de les Expedicions a l'Himàlaia

Aquest repositori conté l'anàlisi de correlació entre variables quantitatives relacionades amb l'històric d'expedicions realitzades a l'Himàlaia.

## Contingut del repositori

* **exped.csv**: dataset csv utilitzat.
* **README.md**: documentació del projecte.
* **PAC2_Visualitzacio_de_dades_Correlation_Matrices.ipynb**: arxiu ipynb amb el codi.
* **PAC2_Visualitzacio_de_dades_Correlation_Matrices.html**: arxiu html amb el codi.
